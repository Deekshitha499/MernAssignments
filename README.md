JavaScript (JS) is a high-level, interpreted, lightweight programming language primarily used to create dynamic and interactive web applications.
It is one of the core technologies of the web, along with HTML and CSS.
JavaScript runs in the browser as well as on the server using environments like Node.js, making it a full-stack language.

Where JavaScript Is Used?
Web development (frontend & backend)
Form validations
Dynamic UI updates
Server-side applications (Node.js)
APIs and backend services
Mobile & desktop apps
Real-time applications (chat apps, dashboards)

Key Features of JavaScript:
Interpreted language (no separate compilation)
Single-threaded with asynchronous capabilities
Event-driven programming model
Dynamically typed
Supports OOPS & Functional Programming
Runs on browser & server
Large ecosystem and community
